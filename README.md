# Miao

Website for Miao, Carrollton K-Town's all-you-can-drink boba lounge and late-night study spot.
2700 Old Denton Rd, Ste 103, Carrollton, TX 75007. Open every day, 1 PM to 2 AM.

Live at https://a2px.github.io/miao/

A static site: plain HTML, CSS and JavaScript, no build step. Cafe details (address, hours,
map coordinates) live in `assets/js/config.js`.
